为什么不是直接 paper trading？

paper trading 的门槛不是“模型看起来有 edge”，而是“模型 edge 能在盘口路径里被执行，并且扣掉 spread、fee、退出机制之后仍然稳定为正”。这次失败在执行层：默认 maker-first 的成交路径亏钱。

最重要的结论：当前问题已经从“估 fair value”推进到“怎么把 fair value 变成可执行正 EV”。

为什么 Binance 1m proxy 在这里可接受？

BTC 1d 这类 Polymarket 市场的结算本身引用 Binance BTCUSDT 的价格规则。对已 closed 市场，用 Binance 1m close 和 reference price 判 UP/DOWN，本质上是在复刻市场规则。它不是泛化到所有 Polymarket 的 official settlement 方案，但对这个市场族是合理 proxy。

执行 Replay：问题集中在“成交后能不能赚”

默认 maker-first 为什么 no-go？

maker-first 的逻辑是挂在 fair value 下方，等待别人打进来。理论上这能省 fee 并获得更好价格；但 replay 显示成交后的路径不够好，55 笔总 realized move 为 -1.4288，正收益比例只有 21.82%。这说明“被成交”本身可能带有不利选择。

taker_hold 为什么值得继续看？

taker_hold 的总 realized move 是 +0.34，正收益比例 55.56%。但交易数只有 36，样本还小，且需要按市场做 out-of-sample 验证。它是候选方向，不是上线结论。

参数网格怎么读？

1080 个参数组合里有 351 个为正。最好的单点集中在 `buffer=0.08`、`gamma=low+medium`、`min_time_to_expiry=30`、`take_profit=0.01`、`stop_loss=0.05/0.08`。但稳定区不够强，说明还不能把它当成稳健策略。

下一步应该解决什么？

1. 继续采样

目标不是堆 snapshot，而是拿到更多完整 settled markets。建议至少 15-20 个 conclusion-grade BTC 1d 市场后再做下一轮正式 go/no-go。

2. 做执行稳健性 WU

重点不是继续调 fair value，而是验证 `taker_hold` 和高 buffer maker 是否能在 leave-one-market-out 下稳定。

3. 维持模型基线

继续用 `iv_digital_v1` 做 baseline；horizon-smile 可以作为诊断字段跟踪，但不要 promote 到 live decision。

下一轮验收门槛

必须按市场通过，而不是按 snapshot 通过

如果只靠一个长采样市场赚钱，策略仍然不合格。需要多个独立市场 PnL 为正，且最大单市场贡献不能过度集中。

执行策略要扣掉真实交易成本

taker fee、spread、退出滑点和 forced exit 都要纳入 replay。否则看到的是理论 edge，不是可执行 EV。

参数不能只有一个点赚钱

如果只有 `buffer=0.08` 的某个组合赚钱，旁边参数都亏，这通常是过拟合。要看参数区域，而不是单个最优参数。
